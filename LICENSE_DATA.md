# Data attribution

This project consumes public data from Sleeper and nflverse/nfldata.

nflverse states that its automated data releases are hosted in `nflverse/nflverse-data` and that schedule/player statistics are available through those releases. See the nflverse repository and release documentation for current source/asset availability and attribution terms.

The engine does not redistribute raw data in this package. It downloads data at runtime and caches it locally for development use.
