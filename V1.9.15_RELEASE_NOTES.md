# FME v1.9.15 — Bye-aware waiver safeguards

- NFL schedule determines current-week bye status for roster players (not zero projections).
- Bye-week QB/RB/WR/TE players are protected from current-week waiver drops when rest-of-season value is unknown.
- Optimizer continues considering available same-position non-bye drops and computes actual lineup points after each move.
- Lineup changes show starters entering/leaving, ignoring swaps between equivalent starting slots.
- Returns `rest_of_season_assessed: false` and warning: future-week projections have NOT been calculated.

## Scope / known limitations
This release does NOT implement future-week opponent projections or full rest-of-season valuation. Bye protection is deliberately conservative and can suppress legitimate waiver upgrades. Future-week valuation should be implemented and validated before removing this safeguard. No measured improvement to Sleeper runtime is claimed.
